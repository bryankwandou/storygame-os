# ECHOES OF MEMORY 🎮

A cinematic story-driven adventure game about memory, loss, and redemption. Built with Next.js, Three.js, and React Three Fiber.

## 🎯 About

**Echoes of Memory** is a narrative-focused game where players explore themes of:
- Memory and identity
- Loss and acceptance
- The choices that define us

## 🎮 Features

- **Cinematic 3D Environments** - Procedurally generated forest, city, and interior scenes
- **Branching Narrative** - Your choices matter and lead to different endings
- **Atmospheric Graphics** - Post-processing effects, dynamic lighting, and particle systems
- **Immersive Story** - Multiple endings based on your decisions
- **Web-Based** - Play directly in your browser, no download required

## 🚀 Tech Stack

- **Next.js 15** - React framework
- **Three.js** - 3D graphics
- **React Three Fiber** - React renderer for Three.js
- **React Three Drei** - Useful helpers for R3F
- **React Three Postprocessing** - Visual effects
- **Zustand** - State management
- **Framer Motion** - UI animations
- **Tailwind CSS** - Styling

## 🎮 How to Play

1. Press SPACE or ENTER to advance dialogue
2. Click on choices to make decisions
3. Explore the story and discover different endings

## 🏃‍♂️ Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
